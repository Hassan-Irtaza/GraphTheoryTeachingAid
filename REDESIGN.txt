GraphTheoryTeachingAid — Warm minimal interface

RUN
Requires the .NET 9 SDK.
From the GraphTheoryTeachingAid folder:
  dotnet run --project Cross-platform/TeachingAidMac.csproj

APPLY TO YOUR EXISTING CHECKOUT
Use the included warm-interface.patch from your repository root:
  git apply --check /path/to/warm-interface.patch
  git apply /path/to/warm-interface.patch
Alternatively, copy the four changed files from Cross-platform/ into your checkout.
